# The Dante’s Infinity 1.1.0-pre.2

The second public pre-release includes The Fury of Doom and fixes five issues reported in [1.1.0-pre.1](https://github.com/dantemorrigan/the_dantes_infinity/releases/tag/v1.1.0-pre.1).

- **Stormbreaker** embeds blade-first in the wall or floor it strikes and keeps the impact angle across world restarts. The skyfall event and dropping the axe with **Q** use the head-down pose.
- **Favorites** cycle with **G** without playing the gauntlet inspection animation. The default inspection key is **I**.
- **Doctor Doom** sits on his throne and stands up before combat.
- **Gauntlet theft** displays a prominent alert to the player whose gauntlet was taken.
- **Infinity Beam** deals damage in Latveria without setting blocks or creatures on fire.

Minecraft **26.1.2**, Fabric Loader **0.20.1 or newer**, Fabric API **0.155.3+26.1.2**, and **Java 25**. Replace the previous mod jar in `mods/`. Use the same `infinity_gauntlet-1.1.0-pre.2.jar` on the server and every client. Back up your world before upgrading.

## По-русски

Второй публичный пре-релиз включает **The Fury of Doom** и пять исправлений по итогам **1.1.0-pre.1**.

- **Гром-Секира** втыкается лезвием в стену или пол под углом попадания. Угол сохраняется после перезапуска мира. При небесном падении и выбрасывании на **Q** секира приземляется головой вниз.
- **Избранное** переключается на **G** без анимации осмотра. Осмотр Перчатки по умолчанию назначен на **I**.
- **Доктор Дум** сидит на троне и встаёт перед боем.
- **Кража Перчатки** показывает владельцу крупный алерт «Дум забирает Перчатку».
- **Луч Бесконечности** наносит урон в Латверии без поджога блоков и существ.

Нужны Minecraft **26.1.2**, Fabric Loader **от 0.20.1**, Fabric API **0.155.3+26.1.2** и **Java 25**. Замени старый файл мода в папке `mods/`. На сервер и клиент каждого игрока ставь один и тот же `infinity_gauntlet-1.1.0-pre.2.jar`. Перед обновлением сделай копию мира.
