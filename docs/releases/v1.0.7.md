# The Dante’s Infinity 1.0.7

Update for Minecraft 26.1.2 (Fabric Loader ≥ 0.20.1, Fabric API 0.155.3+26.1.2, Java 25). Put `infinity_gauntlet-1.0.7.jar` into `mods/` in place of the previous version, on the server and for every player. Existing worlds and config stay compatible. The server and all clients must use the same jar: this version adds a network packet.

## 🖥 Dedicated servers
- **Server rules now reach the client.** The client used to read `abilityBlockChanges`, `realityRadius`, `realityMaxBlocks`, `redSkyRadius`, `redSkyFalloff`, `celestialAimSeconds` and the Soul buff strength from its own config file. The server now sends its values on join and after `/gauntlet reload_config`.
- With `abilityBlockChanges` off on the server, **Reality Inversion no longer leaves ghost blocks** on a client whose own file has it on.
- The red sky radius, the Reality Inversion area, the Sun/Moon lock-on bar and the Soul buff numbers in the HUD now match the server's settings.

## 🌍 Singleplayer
- **Ability state no longer follows you into another world.** Cooldowns and running sessions of Planet Destruction, Time Rewind, Reality Inversion, Reality Strike and the celestial event were kept until the game was closed, so leaving one world and opening another could lock an ability for a long time. They are now cleared when the world closes.

## 🛠 Under the hood
- New client regression test `RuntimeStateTest` (rules sync and per-world cooldowns).
- Releases are now built and published by GitHub Actions from a version tag.
