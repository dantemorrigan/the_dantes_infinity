# 🖥️ Сервер с друзьями: рекомендации

## 1. Требования
- **Java 25**, Minecraft **26.1.2**, Fabric Loader **≥ 0.20.1**
- **Fabric API 0.155.3+26.1.2**
- Мод: `build/libs/infinity_gauntlet-1.0.3.jar` (`./gradlew build`)
- **Один и тот же jar** и у сервера, и у всех игроков (есть свои блоки и сущности).

## 2. Установка
1. Скачать Fabric-сервер для 26.1.2 (fabricmc.net/use/server).
2. В `mods/` положить Fabric API и jar мода.
3. Принять EULA (`eula.txt` → `eula=true`).
4. Запуск (ориентир для 4–8 игроков):
   ```bash
   java -Xms4G -Xmx6G -jar fabric-server-launch.jar nogui
   ```
5. Первый запуск создаст `config/infinity_gauntlet.json`.

## 3. server.properties
| Параметр | Значение | Зачем |
|---|---|---|
| `view-distance` | `8–10` | храмы и города генерируются при загрузке чанков |
| `simulation-distance` | `6–8` | метеориты и квесты нагружают тики |
| `white-list` | `true` | только свои |
| `spawn-protection` | `0–16` | по вкусу; мод его уважает |
| `online-mode` | `true` | оставить |
| `allow-flight` | `true` | иначе сервер выкидывает за полёт Камнем Пространства |

PvP в этой версии Minecraft — не параметр `server.properties`, а gamerule: `/gamerule pvp true` (по умолчанию включён). Без него способности против игроков не работают.

## 4. Конфиг мода
Готовый пресет: [`friends-server-config.json`](friends-server-config.json) (всё включено).
Чтобы смягчить, ставь `false`:
- `allowInfinitySnap`, `allowPlanetDestruction`, `allowCelestialDestruction` — самые разрушительные; `planetDestructionAllPlayers` — Уничтожение планеты видят и уносят в космос всех игроков сервера (если `false` — только тех, кто рядом)
- `abilityPvp`, `mindPlayerGrab`, `soulPlayerDrain`, `extractorPlayerTheft` — против игроков
- `abilityBlockChanges` — запрет менять блоки способностями
- `thanosShipCrater`, `thanosShipWreck` — крушение корабля Таноса (кратер и ~40 тыс. блоков обломков остаются в мире; на слабом сервере можно выключить)

Правки конфига применяются после перезапуска (или командой `/gauntlet reload_config`).

## 5. Права и команды
- `/gauntlet ...` — только операторам (гейммастер).
- Полезно: `/gauntlet stones` (состояние камней), `/gauntlet stones reset` (сброс), `/gauntlet power_shower` (метеоритный дождь для теста).
- Выдавай OP только доверенным: способности ломают мир.

## 6. Бэкапы 💾
Разрушение планет и Снап необратимы.
- Копия папки `world/` **до** первой игры с шестью камнями и перед каждой «большой» сессией.
- Автобэкап раз в час, например cron:
  ```bash
  0 * * * * tar czf /backups/world-$(date +\%F-\%H).tgz /srv/mc/world
  ```
- Хранить минимум последние 24 копии.

## 7. Тест перед игрой ✅
1. Тестовый мир, 2 игрока.
2. Взять Power Stone, перезапустить сервер, проверить, что квесты и камни сохранились.
3. Выдать метеоритный дождь, посмотреть TPS (`/tick query`).
4. Проверить Снап и разрушение планеты на копии мира.
5. Выход/вход игрока посреди способности — сервер не должен падать.

## 8. Правила для друзей 🤝
- Договоритесь: можно ли бить друг друга Перчаткой, кто носит Power Stone (голыми руками убивает за 2 с).
- Камни остаются при смерти, **кроме смерти от руки другого игрока**.
- Броня Uru снижает урон полной Перчатки до 25%.

## 9. Если что-то не так
- **Вылет при входе** → разные версии jar/Fabric API.
- **Лаги** → снизить `view-distance`, `maxActiveMeteors`, `meteorImpactsPerSecond`, `meteorRainSeconds`.
- **Способности не бьют игроков** → проверь `/gamerule pvp` и флаги конфига.
- **Мир сломан** → откат из бэкапа.
