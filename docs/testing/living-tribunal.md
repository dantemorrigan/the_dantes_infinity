# Ручная проверка Великого Трибунала

Используй свежий JAR из текущего `main` и сложность выше мирной. Автоматический вызов работает в выживании. Для спокойной проверки атак можно остаться в креативе и вызвать босса через `/tribunal challenge`: урон игроку отключён. Операторская `/tribunal verdict` запускает катсцену в уже начавшемся бою. В мире должны быть засчитаны сюжетные победы над Локи и Таносом; Перчатка с шестью Камнями должна быть пробуждена и надета во вторую руку. Тренировочный `/gauntlet loki spawn` не завершает сюжет Локи.

1. **Автопоявление.** Вылети в космическую локацию. Примерно через 3 секунды должна открыться чёрная дыра, затем Трибунал должен пройти вперёд через её горизонт: скрытая за дырой часть тела постепенно выходит наружу. Без всех условий он не приходит. `/tribunal challenge` оставлен для ручных повторов.
2. **Модель и перемещение.** Проверь удлинённые ноги, отделённые плечи, масштаб около 100 блоков. Трибунал должен облетать игрока, сохранять дистанцию от планет, Луны и Солнца и оставаться видимым. На обычной скорости попробуй облететь его: он разворачивается с задержкой. Попробуй бой возле Земли и возле газового гиганта.
3. **Семь атак.** Уклоняйся, чтобы увидеть полный цикл: печать приговора, энергетический залп, гравитационный колодец, прицельное копьё, расширяющаяся сферическая волна, звёздная клетка, сверхновая. За предупреждением должен следовать соответствующий пространственный удар. Заряды и лучи должны выходить из ладоней, а поля — связываться с ними. Окно ответной атаки открывается после заклинания.
4. **Перчатка в космосе.** Проверь дальние Удар Силы, Поток времени и Луч; сферические Реальность/Инверсию; Душу и массовую Душу; психический удар по боссу; рывок без земли; удержание и отпускание метеоритного залпа. Рывок не должен проходить через планету. Удары Силы и Реальности должны иметь видимый луч и вспышку попадания, в том числе при наведении на ноги, грудь и голову. Инверсия искажает звёзды вокруг игрока и наносит урон один раз за применение; удержание не добавляет повторных попаданий. Щелчок в этом бою должен выдавать сообщение о блокировке.
5. **Катсцена.** Дойди до одного сердечка. Перчатка должна сняться, пролететь перед камерой и остановиться над раскрытой ладонью, не заходя внутрь руки. Затем она и Камни получают повреждённый вид из белой комнаты, после чего Трибунал уничтожает её. Проверь смерть, возврат позиции, полёта, вещей, Камней и опыта. Дополнительно выйди во время катсцены и зайди обратно: Перчатка должна вернуться ровно один раз.
6. **Меню планет.** Открой Камень Пространства → направления. Проверь русские и английские названия, разные масштабы интерфейса, наведение мышью, стрелки и Enter. Подписи должны помещаться в своих карточках. Выбор только назначает маршрут; перелёт запускается отдельным R.

Для победы используй полную Перчатку и чередуй способности, уклоняясь от предупреждений: у босса 1024 HP. Урон способностей проходит с множителем 0,55, после заклинания босса — 0,85; до множителя одно попадание ограничено 100 единицами. Разные способности не блокируют друг друга обычной неуязвимостью после удара. Регенерация игрока остаётся запечатана. Баланс выживания нужно оценить вручную.

Автоматический бой не должен начинаться заново сразу после поражения. Для автоматического повтора предусмотрены минута передышки и новый выход в космос; ручной вызов доступен отдельно.

## Необязательные автотесты

- Сборка: `./gradlew build compileGametestJava`
- Геометрия всех планет и границ: `java -cp build/classes/java/main src/geometryTest/java/TribunalSpaceCheck.java`
- Попадания по огромной модели, способности, разовая Инверсия и снятие всех HP: `ALSOFT_DRIVERS=null xvfb-run -a ./gradlew runClientGameTest -PonlyTest=TribunalHitTest`
- Полный цикл смерти и восстановления: `ALSOFT_DRIVERS=null xvfb-run -a ./gradlew runClientGameTest -PonlyTest=TribunalTest`
- Автопоявление, семь атак, абилки и RU/EN карточки: `ALSOFT_DRIVERS=null xvfb-run -a ./gradlew runClientGameTest -PonlyTest=TribunalCosmicTest`

Для запуска Minecraft 26.1.2 нужна Java 25. `xvfb-run` нужен только для Linux без графического рабочего стола. Скриншоты и логи сохраняются в `build/run/clientGameTest/`.

После варпа к Земле подлети к её атмосфере: вход в обычный мир должен произойти до столкновения с защитной сферой, с сохранением управляемого полёта. Для короткой проверки возврата и креативного режима: `ALSOFT_DRIVERS=null xvfb-run -a ./gradlew runClientGameTest -PonlyTest=EarthReturnCreativeTest`.
