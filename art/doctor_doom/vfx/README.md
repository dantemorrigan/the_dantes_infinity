# The Fury of Doom

Пак эффектов Доктора Дума для **The Dante’s Infinity**, Minecraft **26.1.2 / Fabric**.

- Сталь и латунь для брони и техники, изумрудные руны для магии, серебро и фиолетовый для времени.
- `preview/Doom_VFX_Preview.png` показывает все эффекты и HUD. В `preview/` также есть зацикленные GIF.
- `src/main/resources/assets/infinity_gauntlet/` содержит прозрачные PNG и Minecraft JSON-описания частиц. Пути совпадают с деревом проекта.
- `integration/doom_vfx.json` содержит идентификаторы, предполагаемые моменты запуска и назначение каждого эффекта.

## Встраивание в мод

Скопировать дерево ресурсов в проект. Для новых частиц зарегистрировать типы и клиентские фабрики по примеру существующих `ModParticles` и `ModParticleProviders`. Для больших наземных знаков и вертикальных ворот использовать плоскости в мире с соответствующей ориентацией. PNG идут последовательностью кадров. HUD нужно отрисовать отдельным клиентским кодом. Боссбар состоит из подложки, обрезаемой по доле здоровья заливки, прозрачной рамки и эмблемы.

В текущем `main` модель Дума уже используется в тизере `DoomTeaserRenderer`. Анимации боя взяты из `doctor_doom/doctor_doom.animation.json`. События в таблице предложены для интеграции и отсчитываются от старта клипа при 20 тиках/с. Для врат используются события существующего тизера `SpaceStone`. Архив содержит ресурсы для разработки. Вызовы в игровом коде и проверка рендера в Minecraft ещё нужны.

## Слои для рендера в мире

Для трёхмерной постановки в паке есть отдельные кадры для плоских телеграфов, волны удара, выхлопа и снаряда светила. Наклонные композиции в превью показывают общий вид эффекта. Для рендера в мире используйте подходящую ориентацию отдельных слоёв.

| Слой | ID | Ориентация |
|---|---|---|
| Зона Эдикта | `edict_warning` | По полу |
| Колонна Эдикта | `edict_column` | Вертикально |
| Зона высадки | `drop_marker` | По полу |
| Волна тарана | `slam_wave` | По полу |
| Выхлоп сапог | `jet_exhaust` | Вертикально |
| Светило для залпа | `sun_projectile` | К камере |

Для ворот тизера `integration/doom_vfx.json` также содержит проверенные отметки `SpaceStone`, включая появление на 28-м тике, толчок на 130-м и начало закрытия после 229-го.

`preview/Doom_Concept.png` — концепт-иллюстрация. Рабочие спрайты и HUD показаны на листе `Doom_VFX_Preview.png`.
