# Доктор Дум

Модель, текстура и проект Blockbench генерируются одним скриптом:

```bash
python3 art/source/doctor_doom/make_model.py art/doctor_doom/preview/doctor_doom.png
```

| Ресурс | Идентификатор |
| --- | --- |
| Геометрия для `GeoModel.load(Identifier)` | `infinity_gauntlet:doctor_doom/doctor_doom.geo.json` |
| Ключевые кадры Bedrock 1.8 | `infinity_gauntlet:doctor_doom/doctor_doom.animation.json` |
| Текстура RGBA 256×256 | `infinity_gauntlet:textures/entity/doctor_doom/doctor_doom.png` |
| Проект Blockbench с 17 анимациями | `blockbench/doctor_doom.bbmodel` |
| Превью | `preview/doctor_doom.png` |

Модель высотой 39 единиц, 16 единиц на блок, 144 куба. Начало координат у ног, фронт по −Z. У каждой грани свой участок текстуры с плотностью 2 пикселя на единицу. Узоры рисуются по координатам модели, поэтому совпадают на соседних кубах.

Восемь анимируемых костей (`root`, `body`, `head`, `arm_r`, `arm_l`, `cape`, `leg_r`, `leg_l`) сохраняют опорные точки, под которые записаны анимации. Наклонные элементы (спад капюшона, пластины наплечников, боковые полотна плаща) вынесены в дочерние кости `bind_*` с фиксированным поворотом, чтобы их поддерживал `GeoModel`. Прорези глаз в маске настоящие, глаза нарисованы на тёмной нише за ними на высоте 34,5.

Скрипт заменяет в проекте Blockbench кубы и текстуру, анимации и идентификаторы анимируемых групп остаются прежними. Правки модели вносятся в скрипт, а не в `.bbmodel`.

Для будущего подключения анимаций понадобится чтение по идентификатору ресурса. Текущий `GeoAnimation.load(String)` ищет файлы в каталоге `thanos/`.

Дум хранится как отдельный ассет без регистрации сущности. В игре его показывает только сцена «Латверия» (`DoomTeaserRenderer`).
