# Доктор Дум

Редактируемая модель Blockbench с вложенной текстурой, скелетом и 17 анимациями лежит в `blockbench/doctor_doom.bbmodel`.

| Ресурс | Идентификатор |
| --- | --- |
| Геометрия для `GeoModel.load(Identifier)` | `infinity_gauntlet:doctor_doom/doctor_doom.geo.json` |
| Ключевые кадры Bedrock 1.8 | `infinity_gauntlet:doctor_doom/doctor_doom.animation.json` |
| Текстура RGBA 128×128 | `infinity_gauntlet:textures/entity/doctor_doom/doctor_doom.png` |

Модель высотой 39 единиц, 16 единиц на блок. Начало координат у ног, фронт по −Z. Наклонные элементы капюшона и плаща вынесены в дочерние кости с фиксированным поворотом, чтобы их поддерживал `GeoModel`. Экспорт анимаций сохраняет ключевые кадры и длительности в секундах. Для будущего подключения анимаций понадобится чтение по идентификатору ресурса. Текущий `GeoAnimation.load(String)` ищет файлы в каталоге `thanos/`.

Дум хранится как отдельный ассет без регистрации сущности и привязки к игровым событиям.
