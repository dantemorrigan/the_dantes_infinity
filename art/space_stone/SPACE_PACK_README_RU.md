# Камень Пространства — базовые эффекты и окна

Небольшой визуальный пак для Minecraft Java/Fabric 26.1.2.

## Содержимое

- Три отдельные прозрачные PNG: окно в Незер, Энд и обычный мир.
- Открытие портала: 4 кадра, затем 4 кадра зацикленного синего ободка.
- Вспышка телепортации: 4 кадра; синие энергетические завихрения: 4 кадра.
- Описания частиц, настройки анимаций, маска проёма и анимированное превью.

Визуальный ориентир — дымные синие разрывы Таноса из «Войны бесконечности»:
рваная кромка, кобальтовая энергия и голубые блики. Без оранжевых рун,
обсидиановой рамы или перекрашивания порталов под цвет измерения.

## Подключение

Содержимое resources/ объединить с src/main/resources/ мода.
PNG textures/space/portal_* — готовые статичные художественные окна-превью.
Сцены внутри них нарисованы в стиле Minecraft: это НЕ скриншоты игры,
НЕ точная копия местности и НЕ живой просмотр координат в другом измерении.
Эти изображения можно использовать сразу как неподвижные окна-заглушки.

Для настоящего окна использовать общую анимированную рамку portal_idle_*,
а в прозрачный проём выводить отрисованное целевое измерение через stencil
или отдельный render target. Рамка остаётся синей для всех трёх измерений.
Для защиты производительности: один вложенный проход, без рекурсивного
рендера порталов, ограниченные разрешение и частота обновления внутреннего вида.
Загрузка нужного мира/чанков, синхронизация и переход — код мода, а не текстуры.

Открытие: кадры 0–3, затем цикл idle 0–3. Закрытие можно проиграть как
opening 3–0. Яркость синих кромок full-bright, alpha blending; пустой центр
и фон должны оставаться прозрачными. Не рисовать чёрную подложку в проёме.
Передняя и задняя стороны — без пропадания при смене угла; для вида сзади
UV и геометрия должны быть согласованы, без зеркального перепутывания мира.

При переходе: короткая вспышка, след синих завихрений; не закрывать весь
экран длительной засветкой. Завихрения подходят и для заряда вокруг перчатки.

integration/*.json — авторские рекомендации, Minecraft сам их не исполняет.
particles/*.json перечисляют кадры, а регистрация и выбор по возрасту
нуждаются в клиентских провайдерах. Пак не меняет ванильный портал Незера.

Проверены PNG/alpha, ссылки ресурсов и JSON. Игровой запуск не проводился.
