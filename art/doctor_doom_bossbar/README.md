# The Fury of Doom · боссбар Доктора Дума

`preview.png` показывает пять вариантов HUD. `preview.gif` показывает
анимации. В `previews/` лежат отдельные собранные образцы с прозрачностью.

| Состояние | Визуальный эффект |
| --- | --- |
| `sovereign` | Изумрудная шкала и парящие искры |
| `warded` | Мятный рунический контур и герб Латверии |
| `overdrive` | Янтарная шкала и электрические дуги |
| `critical` | Оранжевая шкала, пульсирующие трещины и след недавнего урона |
| `defeated` | Пустая шкала, трещины и затухающий пепел |

## Подключение в моде

PNG-слои предназначены для собственного HUD-рендера в Minecraft.
`hud_layout.json` задаёт координаты, порядок кадров и длительности.
Проценты из превью нужны только для демонстрации. Состояние выбирает
логика боя, а ширину полосы определяет фактическое здоровье.

1. Рисуй раму на холсте 512×88, центрируя холст у верхнего края HUD.
   Для компактного масштаба используй 256×44 GUI-пикселя.
2. В прямоугольнике из `slot` рисуй след урона по предыдущему HP,
   затем основную заливку по текущему HP. Обрезай обе полосы слева
   направо по ширине, сохраняя масштаб текстуры. При 0 HP пропускай заливку.
3. Поверх шкалы рисуй кадр из `states.*.frames` от начала холста.
   Кадры длятся по 90 мс. Для поражения проиграй серию один раз,
   затем удерживай последний кадр. Для этой стадии подставь текстуры
   из `frame_override` и `portrait_override`.
4. Вспышку попадания рисуй поверх заливки пятью кадрами по 45 мс,
   обрезая её по ширине текущего HP. Сверху добавь портрет, имя
   штатным шрифтом Minecraft и герб при активном щите.

PNG используют обычный RGBA. Координаты отсчитываются от верхнего
левого угла. Превью собраны вне Minecraft.
