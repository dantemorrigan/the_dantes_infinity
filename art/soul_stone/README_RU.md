# КАМЕНЬ ДУШИ — ИЗВЛЕЧЕНИЕ

Назначение: точечное и массовое извлечение душ, перелёт душ к владельцу перчатки, вспышка поглощения и визуальное усиление здоровья/урона.

soul_wisp — оранжевая душа с хвостом; четыре фазы парения. Размещать у груди/центра моба, затем вести к игроку по дуге. Для массового режима многократно использовать один и тот же спрайт, со сдвигом фазы.
soul_siphon — направленный вправо (+X) поток; ориентировать к игроку и соединять короткими сегментами. Это не бесшовная UV-текстура луча: края намеренно затухают.
soul_mass_wave — полое кольцо, последовательное расширение → разрыв на искры. Для волны по земле использовать нормаль вверх; для сферической волны нужны несколько плоскостей или отдельная геометрия в коде.
soul_absorption — закручивание к центру → яркое поглощение → компактное ядро → затухание. Играть у груди или перчатки при получении души; для состояния усиления повторять редкие импульсы, не держать последний кадр статично.

Точечное применение: одна soul_wisp + поток soul_siphon + финальная soul_absorption.
Массовое: одна расширяющаяся soul_mass_wave, множество soul_wisp по целям, потоки к игроку и импульсы поглощения. Рекомендуется ограничивать одновременно видимые души и сегменты, а не создавать бесконечные частицы.

Убийство врагов, отбор целей, радиус, прирост здоровья/урона, длительность баффа и сетевые пакеты относятся к будущему коду; этот архив их не реализует. Модель моба остаётся оригинальной, подходящей текущему ресурс-паку.

Формат поставки

16 отдельных RGBA PNG, 4 стандартных particle JSON, 4 вертикальных листа с .mcmeta, исходный атлас и превью. Основные текстуры: 64×64 и 128×128, прозрачный отступ 4 px, одинаковые размеры и центр кадров, без сглаживания при уменьшении.

resources/ — заготовка путей для assets/infinity_gauntlet. Это набор ресурсов для интеграции, не самостоятельный устанавливаемый мод или resource pack. particle_presets.json и effect_combinations.json — подсказки интегратору; Minecraft сам их поведение не выполняет. Нужны регистрация частиц и клиентские провайдеры. .mcmeta предназначены для вертикальных листов в authoring; для стандартных частиц используй отдельные PNG и управляй кадром по возрасту.

Циклическая анимация не означает бессмертную частицу: клиент должен удалять её по lifetime или при завершении способности. Не добавляй чёрную подложку; используй straight alpha и full-bright для энергии.

Текстуры не заменяют ванильные материалы. Для совместимости с Minecraft 26.1.2 и активным ресурс-паком брать текстуры блоков и мобов из самой игры. Игровая логика в архив не входит. Репозиторий не изменялся.

Изображения созданы встроенным генератором изображений; техническая нарезка и упаковка выполнены без перерисовки. Промпты приложены.
