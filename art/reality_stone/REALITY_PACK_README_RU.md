# Камень Реальности — небольшой VFX-пак

Для проекта Infinity Gauntlet, Minecraft Java 26.1.2 / Fabric.
8 эффектов × 4 кадра = 32 PNG. Настоящая прозрачность RGBA; по краям каждого кадра оставлено 4 прозрачных пикселя.

## Состав

| Имя эффекта | Размер кадра | Применение |
|---|---:|---|
| reality_charge | 64×64 | Заряд красного эфира у кулака |
| reality_fracture | 128×128 | Растущие трещины и разрывы реальности |
| reality_rewrite | 128×128 | Рассыпание в красные кубические фрагменты |
| reality_restore | 128×128 | Кольцевой импульс возвращения мира |
| reality_butterfly | 32×32 | Красные бабочки вместо мобов; взмах крыльев |
| reality_petal | 32×32 | Лепестки вместо стрел; вращение |
| reality_glass | 32×32 | Мелкие гранёные осколки реальности |
| reality_aether | 64×64 | Текучие красные ленты и фоновые частицы |

Кадры нумеруются от 0 до 3. Порядок одинаков в отдельных PNG, исходных атласах и вертикальных лентах.

## Структура

- `resources/assets/infinity_gauntlet/textures/particle/` — 32 готовых кадра для мода.
- `resources/assets/infinity_gauntlet/particles/` — 8 стандартных Minecraft JSON со списками текстур.
- `resources/assets/infinity_gauntlet/reality_stone/particle_presets.json` — размеры, время кадра, время жизни, зацикливание, яркость.
- `resources/assets/infinity_gauntlet/reality_stone/ability_timeline.json` — предложенная последовательность «Изнанки реальности» и бюджеты частиц.
- `authoring/animation_strips/` — 8 вертикальных лент и `.mcmeta` для предпросмотра/альтернативного подключения.
- `source_atlases/` — два исходных атласа высокого разрешения с прозрачностью.
- `PREVIEW.png` — подписанная обзорная таблица.
- `GENERATION_PROMPTS.txt` — запросы, использованные для генерации встроенным генератором изображений.

## Подключение к текущему моду

1. Скопировать содержимое `resources/` в `src/main/resources/`.
2. Зарегистрировать 8 типов частиц в `ModParticles` и их клиентские провайдеры в `ModParticleProviders`.
3. Добавить значения новых эффектов в `VfxPresets.DEFAULTS` и чтение `reality_stone/particle_presets.json`. Текущий загрузчик проекта пропускает незнакомые имена, поэтому одного JSON недостаточно.
4. Выбирать кадр по возрасту частицы, а не случайно. Для циклических эффектов: `(age / ticks_per_frame) % 4`; для одноразовых: `min(3, age / ticks_per_frame)`. Для заряда лучше привязать номер кадра к доле заряда и удерживать последний кадр.
5. Использовать прозрачный слой частиц с полным освещением. Не рисовать текстуры непрозрачными прямоугольниками. Текстуры уже красные — начальный RGB-множитель белый. Добавлять плавное исчезновение в последней четверти жизни частицы.

Для бабочек рекомендуется собственное движение по дуге и небольшой поворот спрайта. Лепесткам — падение и боковой снос. Осколкам — разлёт с вращением. Трещины можно накладывать на поверхность с небольшим отступом, предотвращающим мерцание; для закрытия проигрывать кадры в обратном порядке.

Вертикальные ленты в `authoring/` стандартно зацикливаются при чтении `.mcmeta`. Одноразовое воспроизведение и остановку задаёт код эффекта; ленты не заменяют отдельные кадры в JSON частиц.

## «Изнанка реальности»

Заряд у кулака → трещины → кубический распад → деформация мира и превращение сущностей. При отпускании — обратное закрытие трещин и импульс восстановления.

Это пак визуальных ресурсов: деформация ландшафта, временная подмена сущностей и восстановление состояния реализуются кодом способности. Для земли и построек использовать настоящие `BlockState` и модели активного ресурспака Minecraft; готовые текстуры грунта здесь намеренно не подменяются. При отмене, смерти, смене измерения и отключении игрока код должен завершать эффект и восстанавливать затронутые объекты.

Предложенный начальный бюджет: не больше 192 живых частиц и 20 новых частиц за тик, радиус 32 блока. Это стартовые значения для настройки, не результаты замера производительности.
