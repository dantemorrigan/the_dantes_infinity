# The Dante’s Infinity — Танос и Sanctuary II

Визуальный пак для Minecraft Java 26.1.2 / Fabric. Модели собраны с нуля в кубическом стиле Minecraft. Открой `preview/asset_preview.png` для предпросмотра моделей и эффектов.

## Модели

| Файл | Содержимое |
|---|---|
| `thanos_gauntlet` | Танос с пустой левой перчаткой. Геометрия и UV штатной модели `gauntlet_in_hand` подогнаны под руку. Используется исходная текстура `gauntlet_model.png` из мода, с пустыми гнёздами |
| `thanos_unarmed_left` | Танос без перчатки. Меч можно прикрепить к правой руке |
| `thanos_double_sword` | Двусторонний меч. Начало координат в центре рукояти, длинная ось X |
| `sanctuary_ii` | Четырёхкрылый корабль с эмиттером высадки и отдельной пушкой |

- `models/blockbench/` — редактируемые проекты с вложенной текстурой, группами и точками вращения.
- `models/geometry/` — геометрия с костями и UV. `models/animation/` — ключевые кадры для этой геометрии в формате Bedrock animation JSON. Для Java нужно подключить импорт или перенести анимации в рендерер мода.
- `models/obj/` — статический экспорт с UV и материалом. В OBJ единица длины равна одному блоку. Прямо в игру эти файлы не ставятся.
- `assets/` — текстуры с прозрачностью, маска свечения, частицы, красное солнце и две текстуры полосы босса.
- `integration/visuals.json` — имена точек привязки, масштабы, цвета и тайминги для рендерера.

Танос высотой 2,75 блока. Сравнение со Стивом в том же масштабе — в `preview/thanos_scale.png`. Меч закрепляется в `sword_socket`, при броске отделяется от руки на 0,63 с и вращается вокруг центра рукояти. Для корабля стартовый визуальный масштаб ×13, ширина в мире около 232 блоков. Луч высадки крепится к `drop_emitter`, выстрел по дракону к `dragon_cannon`. Эти точки проходят через трансформации модели.

## Как собрать сцены

| Сцена | Последовательность |
|---|---|
| Земля | Плавно подвести корабль. Смешать цвет неба с бордовым на 27%, заменить диск солнца на `red_sun` на время сцены. Включить синий `arrival_beam`, на земле показать `arrival_ring` и `arrival_flash`, затем снять луч |
| Незер | Раскрыть вертикальный `nether_rift`, добавить `rift_sparks`. Танос проходит сквозь трещину на анимации `rift_entry`. Закрыть разлом с `rift_close` |
| Край | Плавный подлёт и слабое холодное свечение корпуса `end_hull_halo`. При живом драконе показать заряд `dragon_charge`, выстрел `dragon_ray`, попадание `dragon_impact` и `dragon_shockwave`. После этого показать высадку Таноса. При мёртвом драконе пропустить выстрел |
| Бой | `sword_arc` для взмаха, `sword_sparks` для контакта, `slam_wave` и `slam_dust` для приземления, `armor_hit` для вспышки на доспехе |
| Полоса босса | `boss_frame` и `boss_fill` размером 182×9. Обрезать слой заполнения по текущему HP. Название «Танос – Безумный Титан» отрисовать игровым шрифтом |

В каждом эффекте восемь отдельных кадров RGBA 64×64. Кольца и вспышки проигрывать один раз, лучи и дым циклично. Для лучей повторять текстуру вдоль оси. Текстуры неба и полосы имеют отдельные идентификаторы, чтобы использовать их только в сцене Таноса.

В паке только визуальные ресурсы. Он не включает механику босса, генерацию встречи, дроп и озвучку.
